# Nexora Holdings — Interactive Corporate Website

A modern, interactive corporate website concept built with HTML, CSS, and vanilla JavaScript. The project explores responsive web design, motion effects, and interactive user experiences through a futuristic visual interface.

## Technologies Used

- **HTML5** — Semantic page structure and content
- **CSS3** — Responsive layouts, animations, and visual styling
- **JavaScript (ES6+)** — Interactive functionality and dynamic content
- **Canvas API** — Animated background effects

## Key Features

- **Interactive Particle Background:** Canvas-based visual effects that respond to mouse movement.
- **Dynamic Interface:** Animated headlines, counters, scroll effects, and a live Tokyo clock.
- **Portfolio Showcase:** Interactive cards with 3D-style hover effects.
- **Virtual Driving Experience:** Keyboard-controlled simulated journey to the fictional company headquarters.
- **Meeting Scheduling Interface:** Generates downloadable `.ics` calendar invitations and opens a configurable Zoom link.
- **Command Palette:** Keyboard-accessible navigation using `Ctrl/Cmd + K`.
- **Responsive Design:** Layouts adapted for different screen sizes.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/LikcaniAnxhela/nexora-holdings.git
   ```

2. Open the `nexora-holdings` directory in Visual Studio Code.

3. Open `index.html` in your browser or launch it using the VS Code Live Server extension.

No additional dependencies or build tools are required. An internet connection is needed to load Google Fonts.

## Configuration

Application settings can be modified through the `CONFIG` object in `main.js`, including the meeting link and displayed headquarters information.

The company identity, locations, and portfolio content are fictional and intended for demonstration purposes.
